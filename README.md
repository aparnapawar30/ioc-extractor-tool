# IOC Extractor Tool

## Overview
Python-based Indicator of Compromise (IOC) extraction tool developed for cybersecurity investigations, SOC workflows, and threat intelligence analysis.

## Features
- Extract IP addresses
- Extract email addresses
- Extract URLs
- Extract domains
- Extract hashes

## Technologies Used
- Python
- Regex

## Use Cases
- Threat Intelligence
- Incident Response
- SOC Operations
- Malware Analysis

## How to Run

```bash
python extractor.py
```

This project is intended for educational and authorized cybersecurity research purposes only.
